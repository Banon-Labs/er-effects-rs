# THIS LIST MAY ONLY SHRINK. The checker fails on any offender NOT listed here, so no new one can
# land; it ALSO fails on any name listed here that is no longer an offender, so fixing a counter is
# not finished until its line is deleted. That keeps the file an honest running count instead of a
# graveyard nobody prunes.
#
# To clear an entry, pick one:
#   WIRE   -- the feature exists and the signal is wanted: increment/store at the real site.
#   DELETE -- the feature is unbuilt or was removed: delete the counter AND the oracle it emits.
# Never leave it emitting. A permanently-0 (or sentinel-valued) counter is indistinguishable from a
# feature that ran and did nothing, which is how oracle_title_overlay_cover_render_calls=0 was once
# cited as proof the title cover painted no pixels.
